# SO-ARM101 舵机配置操作教程（setup_motor 脚本）

本教程使用 `setup_motors.py` 完成 leader / follower 两只臂共 12 只舵机的
ID 和波特率配置。整个过程舵机不会动，断力矩状态，可以放心操作。

## 0. 这一步做什么

- **做**：给每只舵机写入唯一 ID（1~6）和统一波特率（1M），写入 EEPROM，掉电保存。
- **不做**：零点标定（那是下一步 calibrate 的事）、不改变任何行程/力矩参数。

每只舵机只需配置一次。以后除非换舵机或报"找不到舵机"，不用再跑本脚本。

## 1. 准备

- **环境**：
  ```bash
  conda activate so101
  cd ~/So-Arm101/setup_motor
  ```
- **硬件**：驱动板 + USB 线、与舵机版本匹配的电源（7.4V 或 11.1V/12V，接错会烧舵机）、
  若干根三针舵机线。
- **接线状态**：整条臂**不要**把舵机串成链——每只舵机此时应是独立散件
  （装在臂上没关系，但互相之间不插线）。
- **关键原则**：任何时刻驱动板上只连接一只舵机；插拔舵机线前先关电源（USB 可一直插着）。

## 2. 配置 Follower（从臂）

1. **只插 follower**：驱动板 USB 接电脑，接通电源。leader 整只不插，
   这样串口唯一，脚本自动识别，全程不需要关心端口号。
2. 启动：
   ```bash
   python setup_motors.py
   ```
   看到 `串口已打开: /dev/ttyACM0`（名字可能不同）即成功。
   若提示发现多个串口，输入编号选择（此时插了几个设备就列几个）。
3. 脚本从 **gripper（6 号）** 开始，逐个提示。每一轮的操作完全相同：

   ```
   ① 用一根三针线把"提示的那只"舵机单独接到驱动板
      —— 它不得连接任何其他舵机，电源已上电
   ② 检查无误后按回车
   ③ 等一两秒（脚本在扫描波特率、写入参数），出现"完成"字样
   ④ 把三针线从驱动板一端拔下，舵机那一端留在原地不拔
   ⑤ 进入下一轮
   ```

4. 六轮顺序（脚本会自己报名字，不用背）：

   | 轮次 | 舵机 | 设为 ID |
   |---|---|---|
   | 1 | gripper（夹爪） | 6 |
   | 2 | wrist_roll（腕旋转） | 5 |
   | 3 | wrist_flex（腕俯仰） | 4 |
   | 4 | elbow_flex（肘） | 3 |
   | 5 | shoulder_lift（肩抬放） | 2 |
   | 6 | shoulder_pan（底座旋转） | 1 |

5. 看到结束提示后，把 follower 的 6 只舵机按顺序串回链条
   （之前留在每只舵机上的线正好都用上），1 号 shoulder_pan 接驱动板。
   **串链前先关电源。**

正常的终端输出长这样：

```
串口已打开: /dev/ttyACM0

电源（匹配电压）和 USB 都要接好；USB 不给舵机供电。

>>> 只把驱动板接到 'gripper' 舵机（将设为 ID 6），按回车继续...
    完成：'gripper' ID = 6，波特率 = 1000000

>>> 只把驱动板接到 'wrist_roll' 舵机（将设为 ID 5），按回车继续...
    完成：'wrist_roll' ID = 5，波特率 = 1000000

...(中间 4 只同理)...

6 只舵机全部设置完成！现在把它们按链条串回去（1 号 shoulder_pan 接驱动板）。
```

## 3. 配置 Leader（主臂）

拔掉 follower 的 USB 和电源，插上 leader，重复第 2 节的全部操作。
两只臂的舵机布局和 ID 完全相同，流程一字不差。

## 4. 验证与下一步

- 全部完成后跑一次：
  ```bash
  lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/ttyACM0
  ```
  连接时的握手会逐个 ping 6 个 ID 并校验型号——6 个全部应答就是 setup 成功的最终确认。
  follower 通过后再同样校准 leader（`--teleop.type=so101_leader`）。
- 一个非正式的快速自检：把串好的整条臂插上再跑一次本脚本，
  报"总线上有 6 只舵机应答"恰恰说明 6 只都在 1M 波特率上活着（然后 Ctrl+C 退出即可）。

## 5. 中断与重跑

- **随时 Ctrl+C 安全退出**，已写入的参数在 EEPROM 里不会丢，已完成的舵机不用重设。
- **重复运行是幂等的**：同一只舵机再跑一遍，只是把相同的 ID 和波特率重写一次。
- **只想重设某一只**（如换舵机后）：走完整流程即可——前面几轮把对应舵机接上让它
  重复写入（无害），做完目标那只后 Ctrl+C 退出。
- 手滑把两只都设成同一个 ID：把其中一只隔离出来重跑对应轮次即可修复。

## 6. 报错对照

| 报错 | 原因与处理 |
|---|---|
| `总线上没有发现舵机` | 三针线没插好/插反；电源没上电（USB 不供电）；接的不是提示的那只 |
| `总线上有 N 只舵机应答` | 还有别的舵机连在总线上（链没断开、或上一只没拔板端线）——断开再按回车 |
| `探测到的舵机型号是 ... 不是 sts3215` | 接错了舵机或型号不对 |
| `无法打开串口` | 端口被占用（关掉其他程序）或无权限（`sudo usermod -aG dialout $USER` 后重新登录） |
| `写地址 X 通信失败` | 按回车后碰掉了线；重新插好再跑这一轮 |

## 7. 安全纪律（重复三遍都值得）

1. 电源电压必须匹配舵机版本——最常见的烧机原因。
2. 电源正负极、三针线方向不能插反。
3. 插拔任何舵机线前关电源。
4. setup 期间舵机不会动；若某只舵机突然上锁/运动，立即断电检查。
